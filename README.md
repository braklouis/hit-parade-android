# Hit Parade for Android

把音乐榜单、歌曲走势和播放数据放在一起看。

**[下载最新 APK](https://github.com/braklouis/hit-parade-android/releases/download/v1.0.2-test.3/HitParade-1.0.2-android.apk)** · [所有版本](https://github.com/braklouis/hit-parade-android/releases) · [反馈问题](https://github.com/braklouis/hit-parade-android/issues)

## 能做什么

- 浏览 Billboard、Apple Music、Spotify、iTunes、Shazam、YouTube、Melon 和美国电台榜单。
- 切换支持的地区，查看 Billboard 往期榜单，以及数据源提供的歌曲排名走势。
- 查看歌曲、专辑和艺人详情，包括 Spotify 累计播放与日增；RIAA 认证和格莱美奖数据按按钮查询。
- 关注歌曲、专辑和艺人，在首页查看它们在所选榜单上的位置。
- 对比两首歌的走势，生成四种版式的分享卡片。

不同来源的更新频率、历史范围和覆盖地区不同。部分历史由本机与服务器记录积累；Melon 等来源仅提供当期榜单。名称匹配、多版本作品和第三方统计可能存在差异，详见应用内「数据来源」。

## 安装

需要 **Android 8.0 或以上**。

1. 在 Releases 下载 `.apk` 文件。
2. 打开文件，按 Android 的提示允许当前浏览器或文件管理器安装应用。
3. 完成安装后打开 Hit Parade。

当前发布的是 **1.0.2 测试版 APK**，使用调试签名，未做代码压缩。它可覆盖此前使用同一签名安装的测试版。Android 8–9 的繁体中文转换受系统限制，可能显示简体；保存分享卡片到相册需要 Android 10 或以上。

每个版本附有 `SHA256SUMS.txt`，可用于核对下载文件完整性。

## English

Hit Parade brings music charts, chart history and play counts together. Browse supported Billboard, Apple Music, Spotify, iTunes, Shazam, YouTube, Melon and US radio charts; follow songs, albums and artists; compare songs; and create share cards.

Supports Android 8.0+ and Simplified Chinese, Traditional Chinese, English, Japanese and Korean. Data coverage and history vary by source. The current APK is a debug-signed test build.

This is a **distribution-only repository for a closed-source app**. It contains documentation and APK downloads, not the application's source code.
